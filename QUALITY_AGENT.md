# Агент проверки вишлиста

Ежедневный агент Codex проверяет опубликованный сайт и русский текст. Автоматизация привязана к текущему чату, запуск — ежедневно в 10:00 по Asia/Qyzylorda. Для локальных запусков нужны открытое приложение Codex, доступ в интернет и доступный компьютер. Это периодическая проверка, а не круглосуточный сервис; она использует лимиты аккаунта Codex. Платные API в приложение не добавлены.

## Проверки

- `pnpm test`: правила бюджета, операции и защита базы в отдельной тестовой БД PGlite.
- `pnpm check:copy`: защита от возвращения удалённых текстов, подборщика и повреждённой кодировки. Это не полноценная проверка грамматики.
- `pnpm build`: TypeScript и production-сборка. GitHub Actions запускает все три проверки при каждом изменении.
- `node --env-file-if-exists=.env.local scripts/healthcheck.mjs`: доступность сайта, маршрутов и изображений, публичный каталог, отсутствие приватных полей в выдаче, настройки и запрет публичной регистрации.
- Агент отдельно вычитывает новые тексты на русском: орфография, грамматика, пунктуация, ясность, единообразие обращений и отсутствие приторных слоганов. При доступном браузере проверяет реальный интерфейс на мобильном и широком экранах: поиск, бюджет, категории, избранное, ошибки загрузки и вход в админку.

## Границы

Проверка не создаёт подарки или брони в рабочей базе, не раскрывает имена гостей, не меняет пароли, права, тарифы или данные владельца. Проверка полноценного входа и загрузки фото требует приватного входа владельца; агент не должен выдавать непроверенный сценарий за пройденный. Сообщает только о новой проблеме, восстановлении после сбоя или необходимом действии. При здоровом неизменившемся сайте остаётся тихим. Любую недоступную проверку фиксирует как ограничение, не как успех.
